
amazon_reviews.py

This Python application uses the Cassandra Python driver to import Amazon review data from a JSON dataset into a Cassandra database.

Features:
- Creates Amazon keyspace
- Creates Reviews table
- Creates ProductCategories table
- Imports review data from JSON
- Displays product categories
- Displays high and low review counts
- Executes user SELECT queries
- Adds and removes columns
- Deletes tables
- Deletes keyspaces
